# 2026-10-16 · v0.8 分页器（常驻翻页条 + 页码格子选页）

驾驶员反馈：「到现在都没做分好用的分页器」——此前只有列表末尾的「加载更多 + 跳页对话框」，
想翻到第 2 页要先把整个列表滑到底，跳远页要输数字，深页数基本没法用。

**驾驶员已确认的做法（AskUserQuestion）**：常驻翻页条 + 保留下滑加载。

## 交互设计

- **常驻翻页条**（列表页底部固定，替换原「跳页」对话框入口）：
  `‹ 第 N / M 页 ⌃ ›`——两边上一页/下一页，中间点开**页码格子**直接选页；加载中显示转圈。
- **翻页条与滚动联动**：N = 列表第一个可见项落在哪一页（滑到哪显示哪页），不是「已加载到哪页」。
- **下载（下滚）加载保留**：列表末尾「加载更多」按钮照旧追加下一页（不动滚动位置）。
- **翻页语义（PageWindow 窗口模型，纯逻辑可单测）**：列表 = 一段**连续页码**的累积窗口；
  - 目标页已加载 → 直接滚动过去（不重新请求）
  - 目标页是窗口下方相邻页 → 追加（下一页；加载完滚到该页首项）
  - 目标页是窗口上方相邻页 → 前插（上一页；加载完滚到该页首项）
  - 跳得很远 → 重开窗口为该单页（回到顶部）
  好处：翻页永远不丢已加载内容，往回翻不重复请求。
- 覆盖四处列表：**首页 / 分类页 / 搜索 / 作者页文章与收藏 tab**（统一同一套控件与模型）。

## 实现

- `app vm/PageWindow.kt`（新，纯逻辑）：`starts`（页码→首项下标）、`pageAt(index)`、
  `actionFor(page)`（ScrollTo/Append/Prepend/Reset）、`afterReset/afterAppend/afterPrepend`
- `app ui/components/Common.kt`：`PagerBar` + `PagePickerSheet`（ModalBottomSheet + 6 列页码
  格子，当前页高亮、打开时定位到当前页附近）；删除旧 `PageJumpDialog`（输入框式）；
  `ListFooter` 文案更新（到底提示带总页数）
- 三个 VM 统一接入：`SiteListViewModel` / `SearchViewModel` / `AuthorViewModel`
  （状态里加 `window` 与一次性 `scrollTarget`；`page`/`maxPage` 改为 window 派生，界面旧调用不动）
- 四个界面：`listState` 提升 + `LaunchedEffect(scrollTarget)` 滚动定位（近距离动画、远距离瞬移）
  + `derivedStateOf` 算 visiblePage + Scaffold `bottomBar` 常驻翻页条（maxPage>1 且有卡片才显示）
