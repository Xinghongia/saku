## 站点机制（2026-10-16 带登录 cookie 全量实测并解码）

| 功能 | 接口 |
|---|---|
| 点赞/收藏 | POST `themes/zibll/action/action.php` `{type=like\|favorite, key=同, pid, _wpnonce=页内 post_action_nonce}` → `{error,action:add\|remove,cuont,msg}`；**实测点赞 add（actived class 出现、cuont 1）→ remove 还原成功**；匿名页也有 nonce（匿名可赞）；匿名收藏按钮带 signin-loader（要求登录） |
| 评论点赞 | 同通道 `type/key=comment_like, pid=评论id`（此前已实测 add/remove） |
| 评分 | POST admin-ajax `{action=zib_star_rating_submit, nonce=页内 zibStarRating 配置, post_id, rating}` → `{error,avg,count,msg}`；重复评=「您已经评过分了」（信息态）。统计组件 `.star-score-content-box`（均值/共N人/五星分布）；**交互星标在侧栏 `.star-score-widget`**（内容区 box 只有统计） |
| 付费区 | 锚定 `#posts-pay`（侧栏另有同名 widget）。未购 `.pay-box.order-type-2`：积分价+VIP价提示+已售+`a.cashier-link`；已购 `.pay-box.paid-box`：订单号/支付时间/金额 + `a[href*=/pay-download/]` 下载按钮 |
| 收银台 | GET admin-ajax `?action=pay_cashier_modal&id={pid}` → 价格/我的积分/隐藏字段 + `action=points_initiate_pay`（**无 nonce**）→ POST；成功刷新页面变已购 |
| 网盘链接 | `GET /pay-download/{id}?key=&down_id=` → 302 `Location`=网盘地址（Golink.resolve 复用：no-follow 读 Location/正文 location.href）；key 随订单、会过期 |
| 评论列表 | 页内 `li.comment#comment-{id}`：头像/名字/等级/`a[data-action=comment_like][data-pid=评论id]`+count+actived/正文/时间/回复链接；分页 `?cpage=N`（嵌套回复在 `ul.children`，父级=最近祖先 li.comment） |
| 评论发表 | POST admin-ajax `{action=submit_comment, comment, comment_post_ID, comment_parent, _wpnonce=评论表单 nonce, captcha_mode=slider + captcha}` → `{error,html,wait_time,comment:{comment_approved}}`；**每次提交都要滑块**（同账户安全/投稿） |
| 作者卡 | `.user-card.author`：头像(vip徽章)/名字+徽章+等级/关注/四项统计(文章/评论/粉丝/人气「9W+」)/简介/more-posts 横滑（封面+标题+时间+浏览量） |
| 头部 | `.article-avatar`：作者链接（**匿名态按钮无 data-action，authorId 从 /author/N 链接锚定**）/名字/徽章/等级/时间（title 有「发布」也有「更新」两种）；关注按钮「已关注」文案=当前已关注 |

## 设计要点与坑（复刻经验）

- 匿名样本与登录样本按钮形态不同（收藏锚点无 data-action、关注/私信缺失）→ 解析以链接/class 锚定，四态各有 fixture
- 评论区以**页面 HTML** 为数据源（REST 没有点赞数/等级/激活态）；骨架占位 li（无 comment-N id）要过滤
- 交互星标在侧栏 `.star-score-widget`，内容区 `.star-score-content-box` 只有统计——评分卡把两者合并展示
- 站点 JS 在失败时也把计数写 0（它的 bug），客户端失败一律回滚快照，不跟
- pay-download 的 key 会过期：解析失败提示重新进入页面
