## 站点机制（2026-10-16 全部带登录 cookie 实测，样本在 research/probe/）

| 功能 | 接口 |
|---|---|
| 用户中心总览 | GET `/user/` 整页 HTML；页内 JS `window._win.post_action_nonce` |
| 登录态 + 明文邮箱 | POST admin-ajax `action=get_current_user` → `{id,is_logged_in,user_data{user_email,…}}` |
| 签到 | POST admin-ajax `action=user_checkin`（无 nonce；成功 JSON 含 details_link） |
| 资料编辑 | `/user/?user_center=data` 表单（name/desc/privacy/gender/address/url_name/url/qq/weixin/weibo/github + hidden action=user_edit_datas+_wpnonce）→ POST admin-ajax |
| 头像/封面 | GET `?action=user_avatar_set_modal`（upload_avatar_nonce/action=user_upload_avatar）与 cover 同构 → **multipart** POST，文件字段名实测 `file`；jpg/gif≤3M |
| 消息通知设置 | `/user/?user_center=msg` 三开关（posts/like/system 勾选发 `on`）+ action=message_shield+nonce |
| 我的等级 | `/user/?user_center=level`（LV1、192/1000、升级还需808、今日+2；`div.pillar-item div.value` 是 LV1..10 阈值 0/1000/3000/…/45000） |
| 我的订单 | POST admin-ajax `?action=user_pay_order&tab=all\|wait-pay` → HTML 片段 `.order-item` |
| 我的资产 | `/user/?user_center=balance`（余额￥/积分/待转入；**积分记录在页内** `#record_tab_points > div`，无需另外 ajax） |
| 我的会员 | `/user/?user_center=vip`（当前状态 + `a.pay-vip[vip-level=1\|2]` 两档，开通按钮本轮只弹提示） |
| 官方认证 | `/user/?user_center=auth`（等级不足提示、门槛 LV5） |
| 打赏收款 | `/user/?user_center=rewards`（rewards_title + 微信/支付宝码，上传 data-tag=weixin/alipay + hidden action=user_set_rewards+upload_rewards_nonce） |
| 账户安全 | `/user/?user_center=account`；弹窗 GET `admin-ajax.php?tab=email\|change_password&action=user_set_modal`（**两种 tab 返回同一份内容**，含 4 个流程表单，样本 `uc_email_modal.html`）：(1) `#tab-bind-email-verify` action=**verify_user**（验证当前邮箱，按钮 form-action=**verify_user_captcha** 发码）；(2) `#tab-bind-email-bind` action=**user_bind_email**（新邮箱+user_agreement checkbox 默认勾选，按钮 form-action=**bind_email_captcha** 发码）；(3) `#tab-change-password` action=**user_change_password**（passwordold/password/password2）；(4) `#tab-reset-password` action=**reset_password**（忘记原密码：email+captch+password2+repassword+repeat=1，按钮 form-action=**resetpassword_captcha**）。**全部表单都带 captcha_mode=slider → 每次提交（含发码）都要滑块**；提交逻辑在 sign-register.js（.captchsubmit / .signsubmit-loader / .user-verify-submit）＋ main.min.js 的 zib_ajax（form-action 覆盖 action、captcha 合入表单）。社交绑定 `/oauth/xx?bind=xx` 外链 |
| 拓展屏蔽 | GET `/user/?sxy_uce_r18=1\|0`（当前态看 `a.sxy-uce-r18-opt.sxy-uce-r18-active`） |
| 消息中心 | `/message/?msg_center=news\|posts\|like\|private\|system`；激活标签看左侧 `ul.tab-nav-theme li.active`（**内容面板不一定带 active 类**，注意）；空态「暂无消息」 |
| 私信会话列表 | msg_center=private 页内 `#user_chat_lists`，每项 `a[data-ajax=…action=private_window&_wpnonce=…&receive_user=…]` |
| 私信窗口/历史 | GET `?action=private_window&_wpnonce=…&receive_user={id}` → `.private-window-content .private-item`（气泡 `div.private-list.right/left`、`.readed-badge` 未读、日期分组 `div.muted-3-color`）+ 发送表单（send_user/receive_user/action=send_private/send_private_nonce）+ 图片（data-name=user_upload_image/upload_image_nonce）+ 黑名单 `a.ajax-blacklist[ajax-href]` |

| 作者页 | `/author/{id}?tab=post\|comment\|favorite\|follow`，分页在路径 `/author/{id}/page/{n}`（`?paged=` 会 301）；粉丝 tab 内 `a[href*=action=author_follow]` 两个子列表（type=followed/follow）；评论 tab 条目 `div.posts-item.no_margin`（**含 .placeholder 的骨架条目要过滤**）；卡片是标准 `posts.posts-item` 可复用 SiteParser |
| 投稿 | `/newposts` 表单（post_title/post_content wp-editor 文本模式/category[] 多选含 `div.ml20` 子级缩进/tags textarea + hidden posts_id=0 + captcha_mode=slider；按钮 `botton[action=posts_draft\|posts_save]`）。提交逻辑在 **page-template.min.js** `.new-posts-submit`：表单字段 + action + 滑块数据 → admin-ajax；响应含 `posts_id`（草稿 id，回填继续保存）、`time`（保存时间）、`url`（预览）、`open_url`（发布后跳转）、`ok`（清表单） |

## 红线与经验
- 付费：只弹 SiteOnlyDialog，**不跳转不开网页**（驾驶员指定）；社交绑定是 OAuth 网页流程，属站点官方外链，点击开系统浏览器（非付费类）
- 写操作 nonce 一律现取现用；私信测试用小号勿扰真人
- **教训**：`text-align:center` 的日期分组 div 容易误吞箭头位置；评论骨架占位要过滤（`div.posts-item.no_margin` 里带 `.placeholder` 的是 loader）；消息中心激活标签在左侧导航 li.active 而非内容面板
- **教训（S9/S10 复刻要点）**：账户安全弹窗两种 tab 返回同一份内容；**每个表单（含发码按钮）都要滑块**，发码按钮的 action 取自按钮 `form-action` 而非表单 action；投稿按钮是主题的 `<botton>`（typo）标签，提交逻辑在 `page-template.min.js` 而非 main.min.js；投稿草稿成功后要回填 `posts_id`
- **验证约定（驾驶员 2026-10-16 指示）**：不做逐页 adb 截图走查（浪费时间）——每批只跑 `:core:test` + `:app:assembleDebug`，界面观感由驾驶员自己在手机上走查
