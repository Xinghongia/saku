# 2026-10-16 · UI 改版 v0.4（主题系统 / 设置页 / 顶部收紧 / 排序下拉）

驾驶员对 v0.3 的反馈：UI 太朴素简陋、顶部空白太多、排序应该是按钮下拉、
设置页入口放「我的」右上角、不要灰色容器底；参考项目指定 rikkahub
（源码已拉取至 `F:\2026project\rikkahub`，AGPL——只借鉴设计思路，未复制任何代码/色值）。

## 两个根因（都是查证后确认的）

1. **顶部空白大**：insets 双层叠加。`AppNav.kt` 外层 Scaffold 未传 `contentWindowInsets`
   （默认含状态栏），NavHost 又 `.padding(padding)` 垫一层；内层各页 TopAppBar 默认
   windowInsets 再垫一层 → 状态栏高度被垫了两次。
2. **灰底**：`Theme.kt` 未定义 `surfaceContainer` 系列，Material3 用默认中性灰生成；
   底部导航（NavigationBar 默认取 surfaceContainer）即灰的来源。

## 主题系统重写

- **`ui/theme/PresetTheme.kt`（新）**：五套自研配色（樱花粉/海洋蓝/春绿/秋橙/极简），
  每套手工定义 Material 3 全量 token（含 surfaceContainerLowest~Highest），
  surface 系列全部带主题色倾向、杜绝中性灰；色值按 M3 色调规则设计（浅 primary=tone40、
  深 primary=tone80）。
- **`ui/theme/Theme.kt`（重写）**：`themeMode`（跟随系统/浅色/深色）+ `dynamicColor`
  （默认开，对齐 rikkahub）+ `presetThemeId` + `amoledDark`（纯黑）；状态栏/导航栏图标
  颜色跟随深浅（强制深色时也清晰）。
- **踩坑**：material3 1.4.0（当前 BOM）的 `MaterialExpressiveTheme`/`MotionScheme`
  仍是 **internal API**（编译报 "it is internal in file"），改用 `MaterialTheme` 包裹；
  待 BOM 升级后再启用 expressive 动效。

## 设置页（新）

`SettingsScreen.kt` + `SettingsStore.kt`（DataStore "settings" 独立于登录会话）：

- **外观**：主题模式三分段；动态取色开关（12+）；主题色卡网格（5 套，
  四色圆预览 + 选中描边对勾，动态取色开时隐藏并提示）；纯黑模式开关
- **浏览**：默认排序（下拉选择，持久化，首页首帧生效）
- **数据**：清理图片缓存（Coil 内存+磁盘，Toast 反馈）
- **关于**：版本（`BuildConfig.VERSION_NAME`，0.1.0→**0.4.0** 顺手修正）、
  开源地址、分享应用、免责声明

## 组件与页面改造

- **`SakuTopAppBar`**（透明融合顶栏 + 可选副标题）：替换全部页面裸 TopAppBar；
  首页 = "SakuraXy / 玄夜の资源小站"，分类列表 = 分类名/篇数
- **`SortMenuButton`**：文本按钮（当前排序名）→ DropdownMenu（选中项对勾、
  高亮主色）；删除横向滚动 `SortChips`，Home/Category 调用点搬进顶栏 actions
- **`SettingsGroup`**（新，自研）：分组卡片 DSL——首尾行 20dp 大圆角 / 中间 4dp 收拢 /
  按下展开动效；40dp 彩色圆底图标（`GroupTone` 三色可选）；容器底用
  `surfaceContainerLow`（带色调、不发灰）
- **底部导航**：`NavigationBar` → `ShortNavigationBar`（Expressive 药丸指示器）
- **insets 修复**：外层 AppNav `WindowInsets(0)` + 4 个 tab 页内层 `WindowInsets(0)`；
  全屏页（分类列表/详情/登录/设置）保持默认 systemBars
- **卡片微调**：`PostCardItem` 底色 → `surfaceContainerLow`、角标色硬编码 → primary、
  内边距 12/10 → 14/12；正文内链颜色硬编码 → `MaterialTheme.colorScheme.primary`
- 分类树改成首页风格卡片行（一级彩色圆底图标、二级缩进轻量行）
