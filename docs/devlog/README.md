# 开发日志（devlog）

命名：`YYYY-MM-DD-标题.md`（标题概括当日主题，如「登录滑块验证」）。
写"今天实现了什么、怎么验证的、遇到什么坑、下一步"，不写流水账，保留能复现的证据（命令、测试数、截图路径）。

命名与用途：
- 同一天多轮不同主题可分多份，标题区分；同一主题的多轮工作合并进同一份，追加小标题即可
- 重大决策的最终版写进 `总设计案.md`，日志里只留指针
- 当前进度与下一道门以根目录 `NEXT.md` 为准，日志是历史记录
